# spudbox

A home media server for a spare PC: it streams your movies, TV shows and
audiobooks to every screen in the house, and runs itself.

- **Watch** in the Plex app on your TV, phone or browser.
- **Request** a movie or show, and it's downloaded, subtitled and in Plex
  when the download finishes.

## Installation

Install [Claude Code](https://claude.com/claude-code), then run:

```bash
git clone https://github.com/mluds/spudbox
cd spudbox
claude
```

Type `/install-spudbox`. It asks for everything it needs and walks you
through the rest.

Requirements, the apps, day-to-day use and backups are in the
[guide](docs/GUIDE.md).
